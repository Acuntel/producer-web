# THE VISION — mined from every directive Brady has given this project

The product: a world-class AI producer you TALK to, that builds real music in front of you,
where a drunk man ends up with a song like John Summit or KETTAMA. Extremely complex behind
the scenes, extremely simple in front.

## The Ten Laws (each traced to his words)

1. **CONVERSATIONAL, INSTANT, VOICE-FIRST.** "Like ChatGPT voice mode... when I talk, it needs
   to be a response." Sub-2s acknowledgment, no dead air, no waiting states he can't see.
2. **HE NEVER TOUCHES THE TOOLS.** "The AI has full agentic control... I should never be able
   to touch it. My input leads as we go." One start/stop. Everything else is voice.
3. **VISIBLE PROOF IT'S WORKING.** "It needs to popup transcribing so I know the system is
   actually listening... I can't see the actual notes or beats." Live transcription, live note
   grids, playhead, section strip. Seeing = trusting.
4. **A GENIUS PRODUCER, NOT A SERVANT.** "It should interview me... play me a sound and ask if
   I like it... stop and say 'look, this one beat here needs to change.'" Interviews, auditions,
   verdicts, proactive call-outs with locations, pauses the music to point.
5. **HUMAN, NOT PERFECT.** "No one likes perfect music. That's AI's problem." The humanization
   engine (seeded swing, pocket, velocity life) is identity, not a feature.
6. **SCIENCE, NOT GUESSES.** "We're turning music into a creative science... if you don't have
   the information, say that and do the research. Don't just guess." The Mind, measured ears,
   song DNA, live web research — always deepening.
7. **ABLETON'S POWER, RADICALLY SIMPLIFIED.** "Every feature Ableton has... but extremely
   simplified down a ton." Sections, arrangements, bar-level edits, transport, isolation,
   stretching — full capability behind the scenes, near-zero surface.
8. **NOTHING IS EVER LOST.** "I need a way to save all my songs and it needs to be better."
   Every version auto-saved; the library holds everything; downloads always work.
9. **EMULATION ON COMMAND.** "Make a song like John Summit or KETTAMA... make it like this
   song." Named lanes with verified DNA; reference → target → build toward it.
10. **EVER-LEARNING.** "The system itself needs to be ever learning, ever improving." Taste
    verdicts persist; killed ideas stay dead; every session smarter than the last.

## The interaction ritual (his repeated shape)
Interview → decisive move → play it → "in or out?" → iterate by voice ("a key higher") →
layer the next element → proactive call-outs between → never re-litigate, never re-ask.

## What "bare bones" means to him
Not missing polish — missing PROOF. When he can't see notes, hear responses instantly, or
trust saving, the system "isn't set up right" no matter what's underneath. Every build
decision optimizes: visible, instant, unbreakable, then deeper.
